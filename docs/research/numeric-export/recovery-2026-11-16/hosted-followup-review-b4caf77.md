## Finding

**P1 — Outside-golden deletion can be accepted as a rename into goldens.** `scripts/numeric/golden-preparation.py:171–175` checks `git diff --name-only` for staged and unstaged paths. With rename detection enabled, name-only reports only the destination of a rename. A tracked `outside.rs` staged as `tests/golden/stdlib/moved.rs` therefore contributes only an allowed path, while the worktree has lost an outside file. Source revision/tree verification reads HEAD and cannot detect this change; devcontainer hashing does not cover arbitrary outside files. The later path-limited patch at line 178 represents the allowed destination and omits the outside removal.

I confirmed this through the real `OWNER.collect` function using the existing synthetic retention fixture in a disposable temporary repository, updating only that fixture's revision/tree/identity records after adding its tracked outside file. After `git mv outside.rs tests/golden/stdlib/moved.rs`, collection returned `complete-review-required`; `outside.rs` was absent and `golden.patch` did not mention its deletion. The guard saw cached `tests/golden/stdlib/moved.rs`, unstaged `tests/golden/stdlib/original.json`, and untracked `tests/golden/stdlib/new.bin`. Original fixture command/identity controls remained enabled. This is a specific uncovered probe, not a repeated passing suite.

Probe results: `/workspace/diagnostic-tools/hosted-followup-review/rename-probe.json`; resulting patch: `/workspace/diagnostic-tools/hosted-followup-review/rename-probe.patch`. A preliminary isolated Git probe independently confirmed the command semantics: `--name-only -z` returned only the destination while `--name-status -z` exposed `R100`, source and destination.

Repair the guard by disabling rename detection for both staged and unstaged path enumeration (`--no-renames`), or by checking both endpoints with a correctly parsed NUL-delimited status format. Add a regression requiring incomplete status for an outside-to-inside rename, including staged state. This is required before accepting the collector's outside-path guarantee or launching the proposed acceptance run. The existing canceled-staged-change regression at `scripts/numeric/tests/test_golden_preparation.py:123–128` is useful but does not cover renames.
