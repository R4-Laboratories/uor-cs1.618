# Pinned backend compatibility diagnostic

This source fixture is separate from the four numeric kernels. Its raw LexLean source verification and production bundle are successful. The canonical pinned PrismPM LCNF exporter rejects comparisons and higher-order iteration; Rust code generation rejects the retained `LexLeanRuntime.Fixed` dictionary type from fixed-width conversion. The source-only `compat-alternatives/` fixture isolates successful direct primitives and another rejected helper-specialization case.

The `artifacts/numeric-task2/compatibility-bundle.tar.gz` archive preserves the complete raw fixture proof bundles, exact generated Lean, source bindings, LCNF IR/roots/coverage, generated Rust packages, logs, native/Wasm replay commands and output digests. It excludes Cargo/Lake build caches. Extraction/codegen success is a diagnostic boundary check, not a full Text/1 application verification.

Reproduction uses `scripts/numeric/run-cached-sdk.sh` throughout (the unchanged d6c263a7 game SDK):

1. In `/workspace/prism/numeric/compat`, run `lexlean lock`, `lexlean fmt`, `lexlean lock`, `lexlean verify`; retain stdout as `artifacts/numeric-task2/compat/source-verify.log`. Run `lexlean production build --request request.json --diagnostic-format json` and retain its exact JSON result.
2. In `/workspace/prism/numeric/compat-alternatives`, run lock/fmt/lock/build, retaining stdout as `alternatives-build.log`.
3. Copy the SDK's `/opt/prismpm/share/conformance-root/vendor/lexlean/language/runtime-1.2/library` into `artifacts/numeric-task2/compat/runtime-source`, make that local copy writable, then run lock/build --all there, retaining stdout as `runtime-build.log`. This is an unchanged source copy, not handwritten Lean.
4. Run `python3 scripts/numeric/compat-stage.py`. It checks generated-output manifest hashes, stages Portable/Collections and both generated fixture modules, and writes a Lake library with `-j2`. In that staged `lean-work` directory, run `lake build PrismGenerated`.
5. Build `scripts/numeric/compat-codegen/Cargo.toml` offline with the SDK Cargo, using `CARGO_TARGET_DIR=/workspace/artifacts/numeric-task2/compat/codegen-target`. Its dependencies are the unmodified pinned SDK `prod-codegen` and `prod-ir` sources. This driver only invokes the real parser/generator APIs; it is not a verifier.
6. Run `python3 scripts/numeric/compat-extract.py`. Its result receipt records each exact selected-root exporter command and generator exit code. The exporter is the immutable SDK seed binary, SHA256 `b0081437c68a576ea0b19805568e8ac8c418cf5b7b366d7881b02f38dbaf77ed`. The retained tool-identity receipt verifies all 160 seed files against the seed manifest and checks the source archive binding.
7. The archived `compile-replay.sh` and `raw-compile-replay.sh` compile actual generated packages and the tracked replay harnesses for native/Wasm. Execute their native outputs; instantiate each Wasm without imports and call `selftest`, expecting zero.

Minimal rejected ordinary helper composition is `Alternatives.repeat4`: the same four checked additions in `nested4` pass extraction, generation and native/Wasm replay. The helper version is rejected on `LexLeanRuntime.checkedAdd._at_.BoundedNumeric.Alternatives.addUInt32.spec_0`. This points to runtime-primitive recognition after specialization in pinned `Prod/Lower.lean`; it does not justify admitting arbitrary external functions. `convertUInt64` and `convertInt64` retain a projection from a supposedly erased `Fixed` dictionary, which reaches unsupported generic type rendering. These repairs and eventual bounded exponent adaptation belong to Task2c. No compiler source, pin, timeout, guard or policy change is included here.

The reconnaissance suggestion to route fixed values through Nat before checked conversion is not source-supported in this pin: `integer_representation` explicitly excludes Nat. Its failed source and diagnostic are retained. Int16 arithmetic itself passes the small direct tests and has enough mathematical range for exponents, but no complete canonical numeric closure is admitted yet.
